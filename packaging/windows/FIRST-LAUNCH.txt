Timegrapher for Windows

Double-click timegrapher-app.exe to start the desktop app.

This build is not signed, so the first time you open each version Windows
shows "Windows protected your PC". Click "More info", then "Run anyway".

timegrapher.exe is the command line tool: open a terminal in this folder and
run  .\timegrapher.exe --help

Install guide: https://github.com/peterhudson/timegrapher/blob/main/docs/install.md
