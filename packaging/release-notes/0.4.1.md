This is a test build for a small group of testers. It is not a public release.

Download the file for your computer below. The steps for opening it the first time are in [docs/install.md](https://github.com/peterhudson/timegrapher/blob/main/docs/install.md). The builds are unsigned, so macOS and Windows will warn you once.

This release fixes two problems in 0.4.0. Nothing else has changed.

## Windows: the programs now start on a fresh Windows
In 0.4.0, the app, the command line tool and the Claude Desktop extension needed `VCRUNTIME140.dll`, which comes with the Microsoft Visual C++ Redistributable rather than with Windows. On a Windows without it, the app stopped at start with "VCRUNTIME140.dll was not found". The programs now carry that runtime inside them, so nothing extra needs installing.

## The panes no longer jump when beats are lost
While the app is listening, the reading cards across the top keep their height when Rate, Amplitude and Beat Error lose their readings and come back. Before, the cards shrank and grew, moving every pane below them. They fit their contents again once stopped or when the window is resized.

## Takes saved by 0.4.0 and 0.4.1 don't open in 0.3.0
As in 0.4.0: takes saved by 0.4.0 or 0.4.1 note in their `session.toml` whether the lift angle was entered or assumed (a `lift_known` line), which 0.3.0 doesn't know. 0.4.1 opens takes from 0.3.0 and 0.4.0. Update the app, the command line tool and the extension together.
