# Contributor Licence Agreement acceptances

One row per person or organisation that has accepted the
[Contributor Licence Agreement](../../CLA.md). A maintainer adds the row
before merging that contributor's first pull request, and checks that
every substantive author of the pull request has a row.

The project owner's own pull requests, including work by AI agents the
owner runs under the owner's account, need no row.
